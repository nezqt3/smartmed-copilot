# Справочник диагнозов для Китая

`icd10_cn_national_clinical_v2_2019.xlsx` — исходное приложение «疾病分类与代码国家临床版2.0» (национальная клиническая версия классификации болезней и кодов, 2.0). Файл опубликован Комиссией здравоохранения провинции Фуцзянь в 2019 году.

- Страница публикации: https://wjw.fj.gov.cn/xxgk/fgwj/zxwj/201904/t20190412_4848943.htm
- Прямая ссылка на приложение: https://wjw.fj.gov.cn/xxgk/fgwj/zxwj/201904/P020190412506737868905.xlsx
- SHA-256 скачанного файла: `435ccd9376fe71920d26d399d831f499a473ae5632654c2e1d6ae1e2d97e9951`

На первом листе колонки «основной код», «дополнительный код» и «название болезни». Из него индексируются 37 289 строк. Поиск возвращает строку источника и не создаёт кодов, которых нет в файле.

К базе добавлены пять кодов из [уведомления Минздрава КНР и государственного управления медицинского страхования от 13 февраля 2020 года](https://www.nhc.gov.cn/yzygj/c100068/202002/858a64332b294a6183fbf8ec4a258d70.shtml). Они переписаны в `icd10_cn_covid_addendum_2020.csv` (SHA-256: `868a2d3b0e719ab62118b1efef328ac6cae9db77823389ade1c98e6242b552d0`). Итого 37 294 строки. Каждый результат указывает `source_file` и `source_row` в соответствующем файле.

Это **не полная редакция 2022 года для клинического применения**. [Минздрав КНР в уведомлении о мониторинге 2024 года](https://www.nhc.gov.cn/yzygj/c100068/202501/3043d2d485c44eeab29ff121c143ebc9.shtml) требует сводную редакцию 2022 года; [руководство 2025 года](https://www.nhc.gov.cn/yzygj/c100068/202506/6a97e937c58b413d8a0ffdcc23d325d4/files/%E3%80%8A%E5%9B%BD%E5%AE%B6%E4%B8%89%E7%BA%A7%E5%85%AC%E7%AB%8B%E5%8C%BB%E9%99%A2%E7%BB%A9%E6%95%88%E7%9B%91%E6%B5%8B%E6%93%8D%E4%BD%9C%E6%89%8B%E5%86%8C%EF%BC%882025%E7%89%88%EF%BC%89%E3%80%8B-20250626185206294.pdf) уточняет, что в ней добавлены 5 кодов и изменены 2 названия. Тождество этих пяти добавлений с кодами из уведомления 2020 года не проверено по самому файлу 2022 года; изменения названий также неизвестны. Минздрав указывает, что файл предоставляется через платформу мониторинга больниц. Поэтому API возвращает `complete_2022_edition: false` и `current_for_clinical_use: false`; найденный код нельзя считать подтверждённым по редакции 2022 года.
