# Production API: фиксированный синтетический регрессионный набор

30 новых случаев, зафиксированных до первого запуска: отрицание/неизвестность, аллергии,
реальный и планируемый приём, дозы, родственник, команда внутри диалога, исправление пациента,
вопрос/совет врача и отдельная third_party реплика. Автор — ассистент, human_reviewed=false.
Это регрессия нового бэкенда, не независимый клинический тест и не человеческая разметка.

Запуск: `.venv/bin/python experiments/05_backend_evaluation/run.py --models qwen3.5:4b qwen2.5:3b`.
Ollama и веса должны быть доступны локально; внешние модельные API не используются.
Результаты в results/ исключены из Git, подробные ответы содержат синтетические тексты.
Публикуемый сводный отчёт: docs/backend-evaluation.md.

## Метрики

- Status accuracy и exact status+value: по всем 6 полям всех запросов; отказ считается ошибкой.
- Grounding rate: среди present/negated проверяется patient, исходная цитата и включение value для present.
  При отсутствии заполненных полей метрика null, не искусственные 100%.
- False-positive rate: ложные present / все неположительные поля эталона.
- False-negative rate: пропущенные present / положительные поля эталона; отказы также считаются пропусками.
- Simulated field corrections: число несовпадений status/value до эталона среди успешных запросов.
  Это НЕ среднее число ручных правок врача; отдельная реальная оценка ещё нужна.
- Workflow passes: экспорт заблокирован → эталонная правка → подтверждение предупреждений →
  экспорт → история generated/edited/confirmed → удаление → 404.

Ошибки и отказы сохраняются; эталоны не исправляются под ответы модели.
Набор и prompt имеют SHA256 / version; генерация temperature=0, seed=42, think=false.
