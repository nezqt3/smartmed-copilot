# Первый эксперимент: извлечение фактов

Задача Павла: понять цепочку **диалог → запрос к модели → JSON → проверка → ошибки**.
Здесь нет обучения. Промпт объясняет задачу, но не меняет веса модели.

## Запуск

Из этой папки:

```sh
python3 run.py --model llama3.2:3b --limit 1
ollama pull qwen2.5:3b
python3 run.py --model qwen2.5:3b
```

Если Ollama недоступен, запусти приложение Ollama или `ollama serve` в отдельном терминале.
Никаких pip-зависимостей нет. Запросы идут только на локальный адрес Ollama.

## Что читать в коде

1. `FIELDS`, `SCHEMA`, `PROMPT`: что именно требуется от модели.
2. `api`: HTTP-запрос к Ollama; это обычная программа, модель работает отдельным процессом.
3. `validate`: проверка структуры, цитат и источника реплик.
4. `compare`: сравнение статусов и значений с эталоном.
5. `main`: запуск и сохранение эксперимента.

Начни с одного примера. Открой `cases.json`, переведи реплики, предскажи ответ сам.
Затем запусти модель и сравни свой прогноз с `answer` и `differences` в `results/.../run.json`.
Первое самостоятельное изменение: добавь четвёртый диалог, где врач спрашивает о температуре,
а пациент отвечает только про кашель. Температура должна остаться `unknown`.
Не меняй одновременно данные, промпт и модель: иначе не поймёшь причину изменения результата.

## Как читать результат

- `validation_errors`: нарушение контракта или неверная буквальная цитата.
- `differences`: точные расхождения с эталоном по `status`/`value`. Полезный синоним тоже
  может не совпасть: здесь специально проверяем копирование исходного фрагмента.
- Совпавшая цитата ещё не доказывает правильную интерпретацию: вопрос врача, отрицание,
  условная фраза и фактическое событие имеют разный смысл.
- `wall_seconds`: время запроса с загрузкой модели. Модель выгружается после каждого случая
  (`keep_alive=0`). Это холодный запуск, а не задержка работающего сервиса.
- `response.load_duration`, `prompt_eval_duration`, `eval_duration`: времена Ollama в наносекундах.
- Сохраняются необработанный ответ, настройки, digest модели, версии и хеши данных/промпта.
  Переводы и эталоны не отправляются модели.

## Что эти данные означают

Три коротких синтетических примера написаны для отладки логики извлечения. Они не содержат
реальных пациентов и не являются медицинской экспертизой или проверкой клинического качества.
Эталоны отражают буквально сказанные факты. Это development-набор: его можно разбирать и менять.
В этом первом контракте нет множественных лекарств, противоречий между репликами и нормализации.
Их потребуется добавить отдельно; результат этого скрипта ещё не полноценная форма истории болезни.

## Дальше: сравнение и обучение

Сначала проверь 3B, затем `qwen2.5:7b` на одинаковых примерах, промпте и настройках.
7B — кандидат для проверки на этом Mac, а не обещание приемлемой скорости.
Для каждого сравнения вручную просмотри ошибки и расход памяти в Activity Monitor.
Сравнение с `llama3.2:3b` здесь проверяет работоспособность; оно не охватывает рынок моделей.
У [Qwen2.5-3B-Instruct](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct) указана
лицензия `qwen-research`, а у [7B](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct) — Apache 2.0.
3B здесь кандидат для учебного исследования; выбор для коммерческого продукта делаем отдельно.

После отладки нужны реальные китайские диалоги и отдельные train/validation/test с разделением
по исходному диалогу **до** генерации вариантов. Лицензию источника проверяем отдельно.
Validation помогает выбрать промпт, модель и параметры обучения; test оставляем для итогового сравнения.
Число обучающих примеров определяем по сложности задачи и кривой качества, а не по трём примерам.
До/после обучения должны совпадать тест, промпт, схема, параметры запуска и по возможности
квантование. Изменение квантования тоже может изменить качество.
`run.py --model ИМЯ_ДООБУЧЕННОЙ_МОДЕЛИ` пригодится после импорта совместимой модели в Ollama.
Сам скрипт не обучает и не импортирует адаптер. На macOS путь обучения выбираем отдельно.

[структурированные ответы](https://docs.ollama.com/capabilities/structured-outputs),
[Qwen2.5 в Ollama](https://ollama.com/library/qwen2.5).
