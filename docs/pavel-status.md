## Замечания преподавателя

Из .env.example убрана строка примера YOUGILE_API_KEY; локальный .env с настоящим ключом не изменялся и не входит в архив. Убран лишний Ruff exclude. Добавлен CI. Автор в аудите берётся из token.
Реализованы сохраняемая очередь, 8000-символьный ввод, роль родственника, конкретная миграция,
полное удаление истории и автоматический срок хранения. README RU/EN/ZH отражают текущий контракт.
Оговорка об отсутствии клинической проверки сохранена.

Regex кашля сохранён с честным описанием ограничения, что допускает пункт P1-5 разбора:
пример «一直干咳» проходит. На реальном корпусе эвристику нужно отдельно проверять и расширять.
