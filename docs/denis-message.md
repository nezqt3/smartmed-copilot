Новый сценарий API:

— POST /v1/auth/login {staff_id, passcode} → access_token; Bearer token ко всем маршрутам черновиков, очереди и препаратов. actor/reviewer из тела убери.
— POST /v1/jobs {turns} → 202/job_id; опрос GET /v1/jobs/{job_id} раз в секунду. succeeded → GET /v1/drafts/{draft_id}, failed → показать error, не экспортировать.
— PUT черновика с expected_version/document. GET /safety перед confirm; врач явно подтверждает обязательные коды и передаёт acknowledged_alerts вместе с expected_version/reviewed:true. Любая правка сбрасывает подтверждение.
— CORS по умолчанию http://127.0.0.1:5173. Для localhost:5173 выставить SMARTMED_BACKEND_FRONTEND_ORIGIN.
— 409 = перечитать версию/проверить предупреждения, 401 = снова войти, 503 queue_full = подождать Retry-After. Не обрезать длинный диалог.
