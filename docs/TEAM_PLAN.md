Задача 05 в работе. Бэкенд раздроблен на несколько небольших карточек; ASR и интерфейс — крупные модули. Оценивать загрузку по оставшемуся времени, а не только числу назначений.

Первый результат Павла: текст → вызов модели → проверенные поля → API.
Первый результат Дена: китайский аудиопример → текст с id/ролями и экран на согласованной фикстуре.

Совместный контракт: id реплики, роль, китайский текст; ответ — поля, статусы, цитаты, предупреждения и версия черновика. Неизвестные сведения отличаются от отрицания.
